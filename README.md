📊 # Interactive Excel Dashboard – Dynamic Data Visualization

An interactive and visually engaging Excel Dashboard designed to transform raw data into meaningful insights using advanced Excel visualization and formatting techniques.

🚀 Dashboard Features
🎯 Speedometer/Gauge Effect using Conditional Formatting
🚦 Traffic Light Indicators to represent performance levels
📊 Dynamic Column & Bar Charts for easy comparison
🥧 Pie Chart for category-wise distribution
🔋 Battery-Style Progress Indicators for KPI visualization
🎨 Conditional Formatting to highlight performance and trends
📌 Interactive KPI-style elements for quick understanding
📈 Clean and attractive dashboard layout focused on data storytelling


💡 # Project Objective

The main objective of this project was to create a professional-looking Excel dashboard that communicates business information quickly and clearly. Instead of relying only on traditional charts, I used creative visual techniques such as speedometers, traffic signals, battery indicators, and KPI visuals to make the dashboard more interactive and user-friendly.

📷  # Dashboard Preview
The dashboard demonstrates how Excel can be used not only for calculations and data analysis, but also for creating interactive and visually appealing business dashboards.
